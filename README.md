# Minimalist Study Tracker

A high-focus, minimalist study timer web application built with React, Supabase, and deployed on Vercel.

## 🚀 Deployment & Configuration

### 1. Supabase Setup
- Create a new project on [Supabase](https://supabase.com).
- Run the SQL queries (or use the Table Editor) to create the `study_sessions` table and configure the Token-Based access model.

**Migration SQL:**
```sql
-- 1. Create Table (if not exists)
create table if not exists study_sessions (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  subject text not null,
  duration_minutes integer not null,
  token text not null
);

-- 2. Enable RLS
alter table study_sessions enable row level security;

-- 3. Create Policy: Access by Token
-- This allows anyone with the correct 'token' to read/write their own data.
-- Note: This effectively makes the token act as a password.
drop policy if exists "Access by token" on study_sessions;

create policy "Access by token" on study_sessions
for all using (true) with check (true);

-- Explanation: The application logic filters by token. The database allows all operations,
-- relying on the uniqueness and secrecy of the 'token' generated by the client.
```

### 2. Vercel Deployment
- Import this repository into Vercel.
- Add the Environment Variables:
  - `VITE_SUPABASE_URL`: Your Supabase Project URL.
  - `VITE_SUPABASE_ANON_KEY`: Your Supabase Anon Key.

## 🛠️ Features
- **Hybrid Storage**:
  - **Guest Mode**: Data is stored locally in the browser (`localStorage`). No login required.
  - **Sync Mode**: Generate a "Secret Key" to backup data to the cloud (Supabase) and sync across devices.
- **Timer**: Distraction-free stopwatch with auto-save.
- **Dashboard**: Heatmap and stats (Daily/Weekly) merging local and cloud data.
- **PWA**: Installable on mobile devices.

## 🔑 Key Management
- Users generate a random Secret Key (e.g., `study-a1b2c3d4`).
- This key acts as their identity.
- **Important**: If a user loses their key, they lose access to their cloud data. There is no email recovery.
