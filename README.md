# Minimalist Study Tracker

A high-focus, minimalist study timer web application built with React, Supabase, and deployed on Vercel.

## 🚀 Deployment & Configuration

### 1. Supabase Setup
- Create a new project on [Supabase](https://supabase.com).
- Run the SQL queries (or use the Table Editor) to create the `study_sessions` table:
  ```sql
  create table study_sessions (
    id bigint generated by default as identity primary key,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    user_id uuid references auth.users not null,
    subject text not null,
    duration_minutes integer not null
  );

  -- Enable RLS
  alter table study_sessions enable row level security;

  -- Create Policy
  create policy "Users can only see their own sessions"
  on study_sessions for all
  using (auth.uid() = user_id);
  ```

### 2. Cloudflare Turnstile Configuration (Crucial!)

This project uses Cloudflare Turnstile for CAPTCHA protection.

**⚠️ IMPORTANT: Keys Must Match ⚠️**

You must ensure the **Site Key** (Frontend) and **Secret Key** (Supabase) are from the SAME environment (either both Test or both Production).

#### Option A: Development / Testing (Recommended First)
- **Frontend (`.env`):** Use the Cloudflare **Test Site Key**: `1x00000000000000000000AA`
- **Supabase Dashboard:** Go to **Authentication > Auth Protection**.
- Enable "CAPTCHA protection" -> "Cloudflare Turnstile".
- **Enter the Test Secret Key:** `1x00000000000000000000BB`
- **Save.**

#### Option B: Production
- Create a widget in [Cloudflare Turnstile](https://dash.cloudflare.com/?to=/:account/turnstile).
- **Frontend:** Update `VITE_TURNSTILE_SITE_KEY` in Vercel Environment Variables with your **Production Site Key**.
- **Supabase:** Update the Secret Key in Supabase Dashboard with your **Production Secret Key**.
- **Allowed Domains:** Ensure your Vercel domain (and `localhost` for dev) are added to the widget settings in Cloudflare.

**Troubleshooting:**
- If you see `captcha protection: request disallowed (invalid-input-response)`, you likely have a mismatch (e.g., Test Key in frontend, Real Key in Supabase).

### 3. Vercel Deployment
- Import this repository into Vercel.
- Add the Environment Variables:
  - `VITE_SUPABASE_URL`: Your Supabase Project URL.
  - `VITE_SUPABASE_ANON_KEY`: Your Supabase Anon Key.
  - `VITE_TURNSTILE_SITE_KEY`: Your Turnstile Site Key (Test or Production).

## 🛠️ Features
- **Email/Password Auth**: Secure login protected by Turnstile.
- **Timer**: Distraction-free stopwatch with localStorage persistence.
- **Dashboard**: Heatmap and stats (Daily/Weekly).
- **PWA**: Installable on mobile devices.
