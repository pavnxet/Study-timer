# Minimalist Study Tracker

A high-focus, minimalist study timer web application built with React, Supabase, and deployed on Vercel.

## 🚀 Deployment & Configuration

### 1. Supabase Setup
- Create a new project on [Supabase](https://supabase.com).
- Run the SQL queries (or use the Table Editor) to create the tables.

**Migration SQL:**

1. **Study Sessions Table** (Data Storage)
```sql
create table if not exists study_sessions (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  subject text not null,
  duration_minutes integer not null,
  token text not null
);

alter table study_sessions enable row level security;

-- Policy: Allow access by token (The token effectively acts as the password)
create policy "Access by token" on study_sessions
for all using (true) with check (true);
```

2. **Identity Registry Table** (User Profiles)
```sql
create table if not exists registered_tokens (
  token text primary key,
  user_name text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table registered_tokens enable row level security;

-- Policy: Allow public registration
create policy "Allow public registration"
on registered_tokens for insert
with check (true);

-- Policy: Allow public lookup by token (Login verification)
create policy "Allow public lookup by token"
on registered_tokens for select
using (true);
```

### 2. Vercel Deployment
- Import this repository into Vercel.
- Add the Environment Variables:
  - `VITE_SUPABASE_URL`: Your Supabase Project URL.
  - `VITE_SUPABASE_ANON_KEY`: Your Supabase Anon Key.

## 🛠️ Features
- **Hybrid Storage**:
  - **Guest Mode**: Data is stored locally (`localStorage`).
  - **Sync Mode**: Link a "Secret Key" to a "User Name" to sync data to the cloud.
- **Identity Registry**: Ensures every Secret Key is tied to a human-readable Name.
- **Timer**: Distraction-free stopwatch with auto-save.
- **Dashboard**: Heatmap and stats (Daily/Weekly) merging local and cloud data.
- **PWA**: Installable on mobile devices.

## 🔑 Key Management
- Users create an identity by entering their **Name**.
- The system generates a unique **Secret Key** (e.g., `study-a1b2c3d4`).
- Users must save this key to restore their profile and data on other devices.
